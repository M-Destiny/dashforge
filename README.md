# ⚡ DashForge

> Modern React admin dashboard with metrics, charts, and user management.

## Tech Stack
React 18 + TypeScript + TailwindCSS + Recharts + Zustand + React Router

## Quick Start
```bash
npm install && npm run dev
```

## Features
- Dark/Light theme toggle
- Responsive metric cards with trend indicators
- Recharts AreaChart + BarChart
- Sortable user table with search
- Collapsible sidebar navigation

## Deploy
| Platform | Command |
|---|---|
| Vercel | Import repo → auto-deploy |
| Fly.io | `fly launch && fly deploy` |
| Railway | Connect repo → auto-deploy |
